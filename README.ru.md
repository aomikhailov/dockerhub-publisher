# Dockerhub Publisher


<img src="https://flagcdn.com/w20/us.png" alt="US flag"> [Read in English](README.md)

## Описание
**Dockerhub Publisher** — скрипт для автоматизации сборки и публикации Docker-образов на Docker Hub.

Если вы регулярно работаете с Docker и сталкиваетесь с необходимостью локальной сборки и публикации образов, рано или поздно появляются вопросы:
- Где хранить параметры сборки и дополнительные файлы?
- Как безопасно передать логин и токен доступа к Docker Hub?
- Как упростить и ускорить весь процесс?

**Dockerhub Publisher** решает эти задачи: он упрощает конфигурацию, делает процесс воспроизводимым и безопасным, снижает количество ручных действий до минимума.

## Установка

1. Клонируйте репозиторий и перейдите внутрь него:
``` bash
    git clone https://github.com/aomikhailov/dockerhub-publisher.git
    cd dockerhub-publisher
```

2. Выполните установку скриптом setup.sh:
   В примере ниже `/opt/dockerhub-publisher/` папка, в которой у вас будут храниться проекты по сборке образов а `docker-image` имя определенного образа.
   Внимание: запись в папку /opt/dockerhub-publisher/ доступна только для root, но вам не обязательно использовать именно эту папку. Подойдет любая другая куда у вас есть право записи.
   Если вы используете другую папку, измените параметр из примера соответственно.

Команда:
``` bash
  ./setup.sh install /opt/dockerhub-publisher/docker-image
```
Так же вы можете установить демонстрационный проект с уже готовым набором файлов для сборки образа. Команда:
``` bash
  ./setup.sh install-demo /opt/dockerhub-publisher/demo
```

## Использование

1. Убедитесь, что Docker установлен. Иначе зачем вам этот скрипт? Следующая команда выведет версию Docker или ошибку если Docker у вас не установлен:
``` bash
    docker --version
```

2. Перейдите в папку созданного вами проекта:

Если вы во время установки установили демонстрационный проект командой `./setup.sh install-demo /opt/dockerhub-publisher/demo`, наберите:
``` bash
    cd /opt/dockerhub-publisher/demo
```

3. Укажите параметры для сборки и загрузки образа в файле `.env`:
``` bash
    DOCKERHUB_USERNAME=<ваш_логин>
    DOCKERHUB_TOKEN=<ваш_токен>
    DOCKER_IMAGE_NAME=<имя_образа>
    DOCKER_IMAGE_TAG=<тег_образа>
    DOCKER_BUILD_ARGS=<аргументы_сборки_если_нужны>
```

4. Доступные команды:

- Сборка образа:
``` bash
    ./publisher.sh build
```

- Публикация образа:
``` bash
    ./publisher.sh push
```

- Полный процесс сборки и публикации одной командой:
``` bash
    ./publisher.sh all
```

## Рекомендации по безопасности
Убедитесь что файл `.env` из вашего проекта не доступен для чтения другим пользователя.
Например, можно выполнить команду:
``` 
chmod 600 .env
```

## Дополнительная информация

- **Мой профиль Docker Hub:** [almihub](https://hub.docker.com/u/almihub)
- **Образ из демонстрационного проекта:** [almihub/tomcat11-jdk23](https://hub.docker.com/r/almihub/tomcat11-jdk23)

### Установка образа демонстрационного проекта из Docker Hub:
```bash
docker pull almihub/tomcat11-jdk23
```

### Запуск контейнера на основе образа из демонстрационного проекта:
```bash
docker run -d -p 8080:8080 \
-e TOMCAT_ADMIN_PASSWORD=<ваш_пароль_администратора> \
--name tomcat almihub/tomcat11-jdk23
```

### Проверка работы контейнера:
1. Убедитесь, что контейнер запущен:
   ```bash
   docker ps
   ```
Контейнер должен отображаться в списке с именем ```tomcat```.

2. Откройте браузер и перейдите по адресу [http://localhost:8080](http://localhost:8080).

Если всё настроено корректно, откроется страница веб-приложения.
